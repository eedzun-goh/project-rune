# Project RUNE - The Digital Mystery Archives
**An Interactive Cloud Security Mystery Archive exploring an AWS IAM investigation and troubleshooting project.**

**Status:** In Progress | Case 001: Planning and Setup

# Overview:

Project RUNE is a beginner-led learning project that explores real-world cloud security and technical support scenarios through interactive mystery cases.

Each case presents a technical problem as an investigation. The goal is to examine the available evidence and identify possible causes, test solutions in an authorised lab environment, and document the findings.

The project combines technical troubleshooting, structured problem-solving and investigative storytelling.

# Case 001 - The Locked Archive

**Scenario:** A user attempts to retrieve a file from an AWS S3 bucket but receives an AccessDenied error.

**Investigation question:** Why is access being denied, and how can you resolve the issue without granting unnecessary permissions?

# Learning Objectives:

- Understand the basics of Amazon S3 and object storage.
- Explore AWS Identity and Access Management (IAM).
- Investigate common causes of S3 AccessDenied errors.
- Apply the principle of Least Privilege.
- Document troubleshooting steps and technical findings.

# Planned Investigation

1. Create a test S3 bucket and upload a sample file.
2. Reproduce an access-denied scenario in an authorised AWS environment.
3. Examine the relevant permissions and configuration.
4. Identify the root cause and test an appropriate fix.
5. Record the evidence, resolution and lessons learned.
